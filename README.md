# 🏥 Healthcare Emergency App

A Flutter mobile application that connects patients with hospitals for fast access to critical medical data.

## 🚑 Problem
In emergencies, doctors lack immediate access to patient history.

## 💡 Solution
Provide instant access to:
- Medical records
- Chronic diseases
- Allergies & medications

## 🛠️ Features
- Patient profile system
- QR / National ID lookup
- Emergency data prioritization
- Doctor search & booking
- Nearest hospital detection

## 🔐 Security
- Secure data handling
- Scalable architecture

## 🧰 Tech Stack
- Flutter
- Firebase
- REST APIs

## 🎯 Impact
- Faster emergency response
- Better patient care
